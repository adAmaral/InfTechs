# Notas das referências metodológicas

## KDD, SEMMA e CRISP-DM: A Parallel Overview

A referência compara KDD, SEMMA e CRISP-DM e destaca que a mineração de dados é uma fase do processo mais amplo de descoberta de conhecimento em bases de dados. O texto enfatiza a necessidade de metodologias padronizadas para orientar projetos de Data Mining, desde a compreensão do problema até a avaliação e uso dos resultados. Para o InfTechs, a principal consequência é não tratar o treinamento de um modelo como etapa isolada: a pergunta de negócio, a compreensão dos dados, a preparação, a modelagem e a avaliação devem formar um fluxo coerente.

## Knowledge Discovery in Database e Data Mining: uma contribuição bibliométrica

A segunda referência apresenta KDD e Data Mining como abordagens aplicáveis à análise quantitativa de grandes conjuntos de dados. O estudo reforça a relevância da descoberta de padrões e da organização sistemática das etapas de investigação. Para o InfTechs, isso sustenta a escolha de uma abordagem orientada a dados para comparar preços, especificações, disponibilidade e desempenho de componentes de computadores.

## Diretriz adotada

O trabalho usará o CRISP-DM como estrutura principal, pois ele organiza explicitamente as fases de compreensão do negócio, compreensão dos dados, preparação dos dados, modelagem, avaliação e implantação. O KDD será usado como referência conceitual complementar para explicar a transformação de dados brutos em conhecimento útil.
